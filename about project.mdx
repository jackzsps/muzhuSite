## 二、 雙動線設計

沐築的目標受眾分為兩種，網站需同時服務兩條動線：

| 動線 | 🏠 動線 A：一般個人戶（B2C） | 🏢 動線 B：設計師（B2B） |
| :--- | :--- | :--- |
| **來訪目的** | 想裝修居家空間，找系統櫃廠商 | 尋找可配合的系統櫃供應商 |
| **關注重點** | 案例照片、價格範圍、服務流程 | 板材規格、合作模式、交期/品質 |
| **決策方式** | 感性為主 — 看案例 → 覺得美 → 聯繫 | 理性為主 — 看規格 → 確認能力 → 洽談 |
| **期望 CTA** | 「免費諮詢 / 預約丈量」 | 「設計師合作洽詢」 |
| **常用管道** | LINE / 電話 | LINE / Email / 表單 |

> **NOTE**：雙動線的實現方式會隨方案規模不同而變化：精簡方案用「區塊分流」，標準方案用「頁面內分區」，完整方案則可獨立出「設計師專區」頁面。

## 五、 正面 SEO 與負面 SEO 終極教材 (2026 趨勢)

### 一、 正面 SEO (White-Hat SEO)
1. **以人為本的高品質內容 (E-E-A-T 原則)**：撰寫獨特觀點與第一手經驗，提升作者透明度與結構化排版。
2. **核心網頁指標 (Core Web Vitals)**：LCP < 2.5 秒、INP < 200 毫秒、CLS < 0.1。確保全站 HTTPS。
3. **白帽連結建立**：創造值得被連結的資產（主題叢集、描述性錨點）。

### 二、 負面 SEO (Black-Hat SEO & Mistakes)
1. **應絕對避免**：購買反向連結、連結農場、隱藏文字/連結、濫用自動化軟體。
2. **常見優化錯誤**：關鍵字堆砌、重複內容、忽視行動裝置體驗、內容稀薄 (如 AI 批量生成的廢文)。

### 三、 2026 年新興趨勢：GEO 與 AEO
- **語意實體優化 (Graph-based Schema)**：建立 Organization、Article、Product 關聯，協助 LLM 理解業務邏輯。
- **實作 Actions Schema**：加入 PotentialAction (如 ReserveAction)，讓 AI Agent 能直接完成任務。
- **倒金字塔式解答結構**：首段先給簡明答案，再展開細節，便於 AI 提取與引用。

## 六、 簡易合約暨訂單核心架構 (v3 極簡版)

合約以「簡單、直白、實用保障」為核心，符合中華民國稅法，保障實質收入。

1. **專案內容與方案勾選**：首頁對比表格大瘦身，左側設有「甲方簽章勾選欄」。
2. **各方案之詳細工序報價明細**：直白好懂的服務項目與經費配比（三萬、三萬五、五萬五）。
3. **付款請款 (勞務報酬單)**：
   - 移除「含稅」字眼。以「專案總價（勞務報酬）」呈現。
   - 註明：請款由乙方提供『勞務報酬單』。報價為乙方實領金額（稅前），代扣稅款與二代健保由甲方負擔並申報。
4. **簡易驗收與修改次數限制**：約定 7 天驗收期，大範圍修改 2 次、細節 3 次為限。
5. **產權轉讓與保密**：付清全款後，代碼與 UI 產權轉移甲方。
6. **售後保固**：乙方簽約欄位採自然人格式（無公司統編，填寫身分證與個人簽章），提供上線後保固。
